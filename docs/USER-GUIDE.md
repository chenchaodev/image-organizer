# 用户手册

> 终端用户使用说明。读者是用户不是开发者,不写内部术语。

## 简介
- Image Organizer 是非破坏式本地图片管理器:扫描你电脑上现有的图片目录建立索引,图片本身保持原样不动;提供高速浏览、重复图片检测与清理功能(更多功能规划中)

## 安装与卸载
- 开发期:仓库根目录 `npm install` 后 `npm run tauri dev` 启动
- 发布版:待首个正式版本发布后补充安装包说明

## 快速上手
- 第一步:启动应用,点击「选择图库目录」选定要管理的图片文件夹
- 第二步:等待索引完成(首次扫描大目录需要一些时间)
- 第三步:在网格中浏览图片;重复检测功能上线后可一键查看重复图片组

## 界面说明
- 主窗口:左侧目录/导航,中间图片网格,右侧详情面板(随迭代完善)

## 设置项
| 设置 | 说明 |
| ---- | ---- |
| 图库目录 | 软件管理的图片根目录(可在启动时选择/更换) |

## 支持的输入
- 图片格式:JPEG/PNG/WebP/GIF 等常见格式(完整支持矩阵随迭代验证后补充)

## 常见问题
- Q:软件会修改或移动我的图片吗? A:不会。非破坏式设计——图片原地不动,软件只建立索引;整理动作(如删除重复项)会先征求确认并移入回收站
